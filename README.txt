MY DAIRY - Milk & Cattle Feed Tracker (works offline)

HOW TO USE
1. Upload ALL files in this folder to any web hosting (Netlify Drop, GitHub Pages, Firebase Hosting, or your own site). HTTPS is required for the Install button.
2. Open the link on the phone, tap Install (or browser menu > Add to Home screen).
3. Data is saved on each phone. Use Settings > Download backup to move data to a new phone.

Opening index.html directly from a file also works, but without the Install button.
Files: index.html (app), manifest.webmanifest + sw.js (install/offline), icon.svg / icon-192.png / icon-512.png (logo).
